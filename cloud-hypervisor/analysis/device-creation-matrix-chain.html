Cloud Hypervisor 设备创建矩阵链路

本文补齐 DeviceManager 的设备创建矩阵：普通 virtio/vhost-user/virtio-fs/vDPA/VFIO/vfio-user 如何进入设备树/PCI transport/热插拔/snapshot-restore。

源码基线：当前仓库工作树。

相关：I/O 设备数据面、DeviceManager 设备链路。

0. 术语与背景

两类设备路径

路径 设备 包装
MetaVirtioDevice → VirtioPciDevice 普通 virtio block/net/rng + vhost-user + virtio-fs + vDPA 统一 MSI-X vector + ioeventfd + PCI hotplug
PciDeviceHandle 直接 VFIO（Vfio）/ vfio-user（VfioUser） 直接 PCI device node，不经 MetaVirtioDevice

restore 从 DeviceTree 恢复拓扑

不是重新猜测拓扑——从 snapshot DeviceManagerState.device_tree + device_id_cnt 恢复，设备重新创建时按 id 取回各自状态。

2. add_pci_devices（统一 VirtioPciDevice）

// vmm/src/device_manager.rs:1648
for handle in self.virtio_devices.clone() {
    let mapping = if handle.iommu { self.iommu_mapping.clone() } else { None };
    let dev_id = self.add_virtio_pci_device(handle.virtio_device, &mapping, &handle.id, handle.pci_segment, handle.dma_handler)?;
    self.device_id_to_bdf.insert(handle.id.clone(), dev_id);  // 记录 BDF
}

所有 MetaVirtioDevice 经 add_virtio_pci_device 统一包成 VirtioPciDevice（MSI-X vector = queue 数+1 + notification ioeventfd + device tree node）。VFIO/vfio-user 不经此路径——直接 PciDeviceHandle::Vfio/VfioUser 表达。
