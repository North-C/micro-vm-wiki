Cloud Hypervisor 运行期控制与热插拔链路

本文追踪 VM 已创建/运行后的控制路径：resize、设备 add/remove、pause/resume，以及如何同时维护 VmConfig、manager 状态、guest 通知。

源码基线：当前仓库工作树。

相关：CPU 运行期/热插拔/迁移、DeviceManager 设备链路、MemoryManager 内存链路。

0. 术语与背景

运行中 Vm 是聚合协调点

API 进入 Vmm 后根据 VM 是否运行选修改 VmConfig 或调运行中 Vm。CPU resize → CpuManager，memory resize → MemoryManager，balloon/disk/net/fs/VFIO → DeviceManager。

三步变更模式

每次在线设备变更通常三步：① manager 创建/删除设备 → ② 更新 VmConfig → ③ ACPI/GED 或设备协议通知 guest。

pause/resume 不是简单停 vCPU

pause 会激活 pending virtio device → 暂停 CpuManager + DeviceManager → hypervisor VM pause。resume 反向恢复。

1. vm_resize（运行前 vs 运行中分流）

// vmm/src/lib.rs:2120
fn vm_resize(&mut self, desired_vcpus, desired_ram, desired_balloon) -> Result<(), VmError> {
    if let Some(ref mut vm) = self.vm { vm.resize(desired_vcpus, desired_ram, desired_balloon)?; }  // 运行中
    else {
        let mut config = self.vm_config.as_ref().unwrap().lock().unwrap();   // 未运行 → 只改 config
        if let Some(v) = desired_vcpus { config.cpus.boot_vcpus = v; }
        if let Some(v) = desired_ram { config.memory.size = v; }
        if let Some(v) = desired_balloon { config.balloon.size = v; }
    }
}

2. Vm::resize（CPU + memory + balloon）

// vmm/src/vm.rs:1892
pub fn resize(&mut self, desired_vcpus, desired_memory, desired_balloon) -> Result<()> {
    if let Some(desired_vcpus) = desired_vcpus {
        if self.cpu_manager.lock().unwrap().resize(desired_vcpus)? {     // CPU resize
            self.device_manager.lock().unwrap().notify_hotplug(CPU_DEVICES_CHANGED)?; }  // ACPI 通知 guest
        self.config.lock().unwrap().cpus.boot_vcpus = desired_vcpus;
    }
    if let Some(desired_memory) = desired_memory {
        let new_region = self.memory_manager.lock().unwrap().resize(desired_memory)?;   // memory resize
        if let Some(new_region) = &new_region {
            self.device_manager.lock().unwrap().update_memory(new_region)?;
            self.device_manager.lock().unwrap().notify_hotplug(MEMORY_DEVICES_CHANGED)?; }  // ACPI 通知（Acpi 模式）
    }
    // ... balloon resize → DeviceManager::resize_balloon → resized event
}

3. notify_hotplug（GED notification）

// vmm/src/device_manager.rs:4565
pub fn notify_hotplug(&self, notification_type: AcpiNotificationFlags) -> DeviceManagerResult<()> {
    self.ged_notification_device.as_ref().unwrap().lock().unwrap().notify(notification_type)
        .map_err(DeviceManagerError::HotPlugNotification)
}

热插拔是 host↔guest 协议：host 创建/标记设备 + ACPI/GED 通知；guest ACPI driver ACK/eject 才算完成。pause/resume 激活 pending virtio + 暂停 CPU/device/hypervisor VM（详见 CPU 运行期/热插拔/迁移 §9）。
