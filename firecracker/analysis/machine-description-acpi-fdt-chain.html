    Firecracker 机器描述：x86_64 ACPI 与 ARM64 FDT 链路

    本文展开 guest kernel 如何知道 CPU、内存、中断控制器、virtio 设备、VMGenID、VMClock 和 PCI/MMIO 拓扑——即机器描述的生成。

    源码基线：当前仓库工作树。

    相关：arch ARM64/x86_64、build_microvm_for_boot。

    0. 术语与背景

    机器描述是启动期生成物

    Firecracker 不像 Cloud Hypervisor 用 GED 承接广泛热插拔——启动后新增设备能力很窄，主要是更新已有设备配置。

    架构 机器描述方式
    x86_64（PC-like） kernel cmdline + MP table + PVH/Linux boot params + ACPI（DSDT/FADT/MADT/MCFG/XSDT/RSDP）
    ARM64（virt-like） FDT（CPU/cache/GIC/timer/PSCI/devices/VMGenID/VMClock/PCI 全部进 device tree）

    1. x86_64 ACPI tables

    // src/vmm/src/acpi/mod.rs:197
pub(crate) fn create_acpi_tables(mem, device_manager, resource_allocator, vcpus) -> Result<(), AcpiError> {
    let dsdt_addr = writer.build_dsdt(device_manager, resource_allocator)?;    // DSDT（设备描述）
    let fadt_addr = writer.build_fadt(resource_allocator, dsdt_addr)?;         // FADT（固定 ACPI）
    let madt_addr = writer.build_madt(resource_allocator, vcpus.len())?;       // MADT（中断控制器/IOAPIC）
    let mcfg_addr = writer.build_mcfg(resource_allocator, PCI_MMCONFIG_START)?;// MCFG（PCI ECAM）
    let xsdt_addr = writer.build_xsdt(resource_allocator, fadt_addr, madt_addr, mcfg_addr)?;
    writer.build_rsdp(xsdt_addr)                                               // RSDP（入口）
}

    x86_64 ACPI 在 configure_system_for_boot 最后创建（仅 x86_64），描述 interrupt controller/vCPU/VirtIO 设备。

    2. ARM64 FDT

    // src/vmm/src/arch/aarch64/fdt.rs:67
pub fn create_fdt(guest_mem, vcpu_mpidr, cmdline, device_manager, gic_device, initrd) -> Result<Vec<u8>, FdtError> {
    let root = fdt_writer.begin_node("")?;
    fdt_writer.property_string("compatible", "linux,dummy-virt")?;
    fdt_writer.property_u32("#address-cells", ADDRESS_CELLS)?;
    fdt_writer.property_u32("interrupt-parent", GIC_PHANDLE)?;
    create_cpu_nodes(&mut fdt_writer, &vcpu_mpidr)?;      // CPU（MPIDR 填 reg + cache from host sysfs）
    create_memory_node(&mut fdt_writer, guest_mem)?;
    create_chosen_node(&mut fdt_writer, cmdline, initrd)?;  // cmdline + initrd 也进 FDT
    create_gic_node(&mut fdt_writer, gic_device)?;          // GIC
    create_timer_node(&mut fdt_writer)?; create_clock_node(&mut fdt_writer)?; create_psci_node(&mut fdt_writer)?;
    create_devices_node(&mut fdt_writer, device_manager)?;   // virtio-mmio 设备
    create_vmgenid_node(/*...*/)?; create_vmclock_node(/*...*/)?;
    create_pci_nodes(&mut fdt_writer, &device_manager.pci_devices)?;
}

    ARM64 必须先配置 vCPU + 读 MPIDR/cache 再生成 FDT——guest CPU/cache 视图来自 FDT + 寄存器共同约束。override_clidr() 让 CLIDR_EL1 与 FDT cache 一致。VMGenID/VMClock 两种架构都有（x86 经 ACPI、ARM64 经 FDT）。

    3. 能力边界

    机器描述启动期固定，不支持运行期热添加设备（只支持已有设备 config update）。VMGenID snapshot restore 会注入新 generation ID 中断。ARM64/x86_64 差异在描述机制（FDT vs ACPI），不在设备协议本身。
