Firecracker MMDS 元数据网络链路

本文展开 MMDS 如何从 API 配置变成 guest 可访问的 link-local metadata service。

源码基线：当前仓库工作树。

相关：virtio net 数据面、runtime device update。

0. 术语与背景

MMDS 不是独立 host HTTP server

它是挂在 virtio-net 设备内部的轻量网络栈，拦截发往 MMDS IPv4 的 ARP/IPv4 帧，把 HTTP 请求转成对 Mmds data store 的访问。

关键边界

  • API 侧 PUT/PATCH /mmds 修改 metadata；guest 侧 PUT 只申请 IMDSv2 token，不写 metadata。
  • PUT /mmds/config（绑定网卡/IPv4/version/imds_compat）只能启动前设置；启动后允许更新 MMDS 数据但拒绝改配置。
  • MMDS 帧不计 rate limiter（rate_limiter_replenish_op 补回 token）。
  • MMDS 栈无 ARM64/x86_64 条件分支——差异在 virtio-net 设备暴露路径。

1. MMDS 帧 detour（write_to_mmds_or_tap）

// src/vmm/src/devices/virtio/net/device.rs:494
fn write_to_mmds_or_tap(mmds_ns, rate_limiter, headers, frame_iovec, tap, guest_mac, metrics) -> Result<bool, NetError> {
    let header_len = frame_iovec.read_volatile_at(headers, 0, max_header_len)?;
    let headers = frame_bytes_from_buf(&headers[..header_len])?;
    if let Some(ns) = mmds_ns && ns.is_mmds_frame(headers) {     // 判断是否 MMDS 帧
        let mut frame = vec![0u8; frame_iovec.len() - vnet_hdr_len()];
        frame_iovec.read_exact_volatile_at(&mut frame, vnet_hdr_len())?;
        ns.detour_frame(&frame);                                 // MMDS 消费（HTTP → data store）
        Self::rate_limiter_replenish_op(rate_limiter, frame_len);  // 补回 limiter token（不计 limiter）
        Ok(true)                                                 // MMDS consumed
    }
    // ... 否则检查 MAC spoofing → Tap::write_iovec ...
}

2. MMDS API（PUT/PATCH data）

// src/vmm/src/rpc_interface.rs:235
fn mmds_patch_data(mut mmds: MutexGuard<Mmds>, value: serde_json::Value) -> Result<VmmData, VmmActionError> {
    mmds.patch_data(value).map(|()| VmmData::Empty).map_err(|err| match err {
        DataStoreLimitExceeded => VmmActionError::MmdsLimitExceeded(DataStoreLimitExceeded),
        _ => VmmActionError::Mmds(err),
    })
}

runtime controller 允许 PatchMMDS/PutMMDS（更新数据）+ GetMMDS（查询）；拒绝 SetMmdsConfiguration（启动前配置，post-boot 不允许改绑定/IPv4/version）。

3. 能力边界

问题 Firecracker 表现
MMDS 是独立 HTTP server 否，virtio-net 内部轻量网络栈
guest 如何访问 发 ARP/IPv4 帧到 MMDS IPv4（link-local）
MMDS 帧是否计 rate limiter 否（补回 token）
启动后能否改 MMDS 配置 不能（只能改数据）
ARM64/x86_64 差异 MMDS 栈无分支，差异在 virtio-net 暴露路径
