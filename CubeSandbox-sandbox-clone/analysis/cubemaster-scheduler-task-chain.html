CubeMaster Scheduler 与 Task Retry 链路

本文展开 CubeMaster 控制面：metadata 如何进入 scheduler、创建请求如何选节点并调用 Cubelet、后台 task retry 的真实作用范围。

源码基线：当前仓库工作树。

相关：API 到 Cubelet 创建链路、CubeMaster 缓存一致性。

0. 术语与背景

CubeMaster 不直接创建 VM

它把 API 请求规范化为 RunCubeSandboxRequest，把资源/模板/亲和性放入 SelectorCtx，再选节点并调 Cubelet gRPC。

创建路径 = 同步等待缓冲队列

CreateSandbox() 把 createSandboxContext 放入 scheduler buffer，调用方等 done 直到成功/失败/超时。重试在 handleCubelet() 内部（可重调度到新节点，也可在可复用错误码下重试同链路）。

task 包 ≠ create 主路径

后台队列主要处理 Destroy/CreateImage/DeleteImage/UpdateSandbox + create 失败后的异步 Destroy 清理。

1. SelectorCtx + Select

// CubeMaster/pkg/scheduler/selctx/selectcontext.go:19
type SelectorCtx struct {
    Ctx context.Context; ReqRes *RequestResource
    lastBadFilters []*node.Node; result node.NodeList
    selName string; rSelect weighted.W; resultWithScore node.NodeScoreList
    Affinity Affinity; InstanceType string
}
// CubeMaster/pkg/scheduler/schedule.go:25
func Select(selCtx *selctx.SelectorCtx) (*node.Node, error) {
    if err := runPreFilter(selCtx); err != nil {
        if shouldSkipBackoffForTemplate(selCtx) { return nil, err }
        if err = runBackoffFilter(selCtx); err != nil { return nil, err }
    }
    if err := runFilter(selCtx, scheduler.filter); err != nil {
        if shouldSkipBackoffForTemplate(selCtx) { return nil, err }
        return BackoffSelect(selCtx)        // filter 失败 → backoff 重试
    }
    if err := runScoreFilter(selCtx, scheduler.score); err != nil { return nil, err }
    return selCtx.LeastRandomSelect(config.GetConfig().Scheduler.PrioritySelectNum), nil
}

调度链：PreFilter（健康/熔断/affinity/MVM 上限/metric 超时）→ Filter（template locality/resource）→ Score（realtime CPU/memory）→ LeastRandomSelect。失败走 BackoffSelect。

2. callCubelet + retry

handleCubelet() 循环：schedule() 选节点 → IncrNodeConcurrent → cubelet.Create → 错误码判断 retry/reschedule → DecrNodeConcurrent。circuit break 错误码 → AddLastBadNode（下次跳过）。详见 API 到 Cubelet 创建链路 §6。

3. 能力边界

CubeMaster 这段 Go 控制面不区分 arm64/x86_64。差异落在节点 metadata/instance type/Cubelet-CubeShim-VMM 能否消费相同请求。task 包后台队列不承载 create 主路径（只处理 Destroy/CreateImage/DeleteImage/UpdateSandbox + create 失败清理）。
