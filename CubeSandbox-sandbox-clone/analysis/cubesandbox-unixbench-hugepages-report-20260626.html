CubeSandbox UnixBench 静态大页影响测试报告

测试环境

项目 值
远端机器 私有 ARM64 benchmark host（已脱敏）
主机 aarch64, Linux 6.6.0-132.0.0.111.oe2403sp3.aarch64
CubeSandbox 模板 tpl-irqbypass-xarray-envd-shm2g-20260624101600
沙箱规格 2 vCPU / 2G（模板资源 cpu=2000m,mem=2000Mi）
UnixBench BYTE UnixBench 6.0.1，./Run -c 2
测试方式 宿主机构建 UnixBench 后上传到每个沙箱执行，避免包管理器/网络下载影响跑分
本地结果目录 analysis/remote-results/cubesandbox-unixbench-final-20260626-1548/，analysis/remote-results/cubesandbox-unixbench-zram40-20260626-1810/

汇总结果

结论：在本次 2 vCPU / 2G 单沙箱 UnixBench 场景中，宿主机预留约 40% 静态大页后，UnixBench 综合分数从 3241.80 降至 3192.40，下降约 1.52%。在同样 40% 静态大页基础上启用 40% host zram swap 后，综合分数为 3222.90，相对 40% 大页组回升 0.96%，相对基线仍低 0.58%。

UnixBench 内存占用

第三组测试在沙箱内以 5s 间隔采样 UnixBench 相关进程 RSS/VSZ、沙箱 /proc/meminfo 和 cgroup memory，共采样 332 次，覆盖 1674s。

指标 数值
UnixBench 相关进程合计 RSS 峰值 17724 KiB，约 17.31 MiB
UnixBench 相关进程合计 RSS 均值 13857.46 KiB，约 13.53 MiB
UnixBench 相关进程合计 VSZ 峰值 109292 KiB，约 106.73 MiB
UnixBench 相关进程数峰值 35
沙箱 cgroup memory.current 峰值 58589184 bytes，约 55.88 MiB
沙箱 MemAvailable 最小值 1746284 KiB，约 1705.36 MiB
沙箱内 SwapTotal 0 KiB

说明：zram 是宿主机侧 swap 补充，不会作为沙箱内 guest swap 暴露；因此沙箱内 /proc/meminfo 的 SwapTotal 仍为 0。宿主机 /proc/swaps 显示 /dev/zram1 已启用，但测试期间 Used=0，zram 的 io_stat 也未出现读写，说明 UnixBench 在该规格下没有触发宿主机 swap 压力。

清理状态

测试脚本完成后已恢复宿主机大页，并移除了临时 zram swap。最终宿主机状态：

SwapTotal:       4194300 kB
SwapFree:        4194300 kB
HugePages_Total:       0
HugePages_Free:        0

远端没有残留本次测试驱动进程；cubemastercli cubebox list --all 只剩一个历史 exited 沙箱，不属于本次测试。最终 /proc/swaps 只剩测试前已有的 /dev/dm-1，无 /dev/zram* swap 设备残留。
