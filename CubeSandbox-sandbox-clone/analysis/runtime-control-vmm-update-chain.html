CubeSandbox 运行期控制与 VMM 更新链路

本文分析 pause/resume、exec、Task.Update、virtio-fs 更新、设备热插拔和 rollback update 如何从平台 API 落到 CubeShim 与 VMM。

源码基线：当前仓库工作树。

相关：Rollback/Runtime Update、VMM device restore、横向 runtime control。

0. 术语与背景

运行期控制不是单纯 VMM API

公开入口在 CubeAPI/CubeMaster → Cubelet → containerd task → CubeShim → CubeHypervisor。

操作 CubeAPI/Master Cubelet CubeShim
pause/resume sandbox update Task Pause/Resume pause_vm/resume_vm（pod scope only）
exec sandbox exec Task Exec agent exec
Task.Update — Task Update update_container + update_sandbox + update_ext::update_route
VmSetFs — — ApiRequest::VmSetFs → fs worker update_filter
rollback sandbox rollback RollbackSandbox rollback_vm（删旧 VM + restore 新 VM）

关键边界：CubeAPI/Master 只接受 pause 和 resume；设备热插拔有两层（Master task handler 识别 add/remove，但开源 Cubelet 返回"不支持 cloud disk hotplug"；shimapi 仍有 Task.Update 注解通道）。

1. CubeShim pause/resume（pod scope only）

// CubeShim/shim/src/service/task_srv.rs:581
async fn pause(&self, ctx: &TtrpcContext, _req: api::PauseRequest) -> TtrpcResult<api::Empty> {
    if ctx.metadata.get("pod_scope").is_none() { return Err("pause only supported at pod level"); }
    let mut sb = self.sandbox.lock().await;
    if !sb.normal().await { return Err("sandbox not in normal state"); }
    sb.pause_vm().await?;   // VMM pause（VmPauseToSnapshot 不删 VM，见 rollback 文档）
}
// :603  resume 同理：要求 paused 状态 → resume_vm

2. CubeShim Task.Update（资源 + annotation + update_ext）

// CubeShim/shim/src/service/task_srv.rs:380
async fn update(&self, _ctx, req: api::UpdateTaskRequest) -> TtrpcResult<api::Empty> {
    let mut sb = self.sandbox.lock().await;
    if sb.paused().await { return Err("sandbox not in normal state"); }
    if let Some(resource) = req.resources.as_ref() {
        sb.update_container(&req.id, &res).await?;    // 容器资源 → agent UpdateContainer
    }
    sb.update_sandbox(&req.annotations).await?;        // sandbox annotation
    update_ext::update_route(&mut sb, &req.annotations, &self.log).await?;   // 扩展 route（如 VmSetFs）
}

update_ext::update_route 处理 cube.update.route 类 annotation，包括 VmSetFs（在线更新 fs allowed dirs，不删 VM）和 rollback（删旧 VM + restore 新 VM）。两者都经 CubeShim/VMM，但语义完全不同。

3. 能力边界

CubeSandbox 公开运行期控制面很窄：只 pause/resume（pod scope）+ exec + update（资源 + annotation + fs allowed dirs update）。设备热插拔在开源 Cubelet 中明确不支持 cloud disk hotplug。rollback 是 snapshot-backed restore（删旧 VM），不是在线修改。
