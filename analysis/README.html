Analysis 导航入口

本目录是顶层分析入口。

项目级源码链路统一放在 analysis/projects/<project>/，由私有分析控制仓维护。 各源码仓库是只读研究输入；旧项目内 analysis/ 只在明确任务中作为迁移输入或私有证据根。

顶层 analysis/ 只放四类内容：

  1. 项目路线总览
  2. 跨项目专题判断
  3. ARM64 网络线索引与样本体系
  4. 样本资产入口

当前 CubeSandbox 源码基线

从 2026-07-31 起，新的 CubeSandbox 分析默认以 canonical 工作树 CubeSandbox/ 为源码来源：

  • 分支：0731-after-v0.6.0
  • 完整提交：5135a40d86c94a85fe2521fd9ed913ac5fd6cfd9
  • 源码提交时间：2026-07-29T18:54:38+08:00
  • 基线选择日期：2026-07-31
  • 选择时引用关系：HEAD = origin/master

完整提交哈希是权威的基线身份；分支名和远端引用仅用于说明选择时的状态。除非后续任务显式记录新的完整提交及刷新范围，否则源码事实、配置与测试证据均应锚定上述提交。

CubeSandbox-sandbox-clone/、CubeSandbox-arm64-adaptation/ 等旧的 dirty worktree 只可在任务明确点名时作为历史或实验性证据，不是默认来源。现有 CubeSandbox 文档仍以各自原先记录的提交为准；设置本基线不会自动把旧结论重新归属到新版本，必须先显式复核并更新版本与证据标注。

0. 如果你是第一次想系统学习

如果你目标是“完整理解这些轻量化虚拟机、学会如何构建高性能 VM、建立性能与安全的设计依据”，先从这里开始，再进入下面的四类读法：

  • 轻量化虚拟机设计全景与学习路线：完整面貌 + 四段式学习课程，贯穿已有 chain 文档。
  • 性能设计依据跨项目专题分析：性能从哪些设计决策来，带实测锚点。
  • 安全设计依据跨项目专题分析：安全怎么推理、怎么取舍，威胁模型与纵深防御原理。
  • 分析框架改进意见：框架自身的完整性盘点与改进优先级。

这四份是“综合学习层”，建立在下面的机制专题之上。学机制读专题，学取舍读设计依据，两者互补。

3. 当前重点

自 2026-07-31 起，当前阶段按三条主线推进：

  1. Snapshot、Restore、Migration：从 Snapshot / Restore / Clone 跨项目专题 和 Restore 后 Guest 不可用验证清单 进入，继续回答内存、设备和存储状态如何捕获与恢复，版本和架构兼容边界在哪里，失败如何检测、回滚，以及现有 snapshot/restore 状态模型如何约束 migration。
  2. 存储与内存：从 存储、rootfs 与共享文件系统、Virtio 传输与设备数据路径 和各项目存储链路进入，继续回答 rootfs/块设备/share-fs 与内存布局、dirty page、CoW/page fault、缓存和回收如何相互作用，以及这些机制怎样影响恢复一致性和资源开销。
  3. 性能提升：围绕一个明确瓶颈深入还原端到端关键路径、数据结构与所有权、并发/同步/排队、内存与 I/O 成本，以及 guest/host、userspace/kernel、KVM 和架构边界；通过 profiling 与定性或定量成本模型定位主导成本，再完整评估优化候选、预期收益、取舍、不变量、架构差异、回退风险和验证设计。允许做最小范围的前后测量，但测量必须服务于已声明的优化假设，记录目标指标、实验边界和回退判断，不能自行扩展为独立 benchmark campaign 或性能报告。对应社区存在相关性能报告时，必须在有关分析文档中解读其来源、版本、环境、workload、指标与统计方法，映射到本地源码机制，并明确可比、部分可比或不可比。

当前阶段暂缓两类工作：

  • CubeSandbox ARM64 2-vCPU Restore 根因调查：既有证据保留为未解决的历史/私有参考，但不继续采集 trace、定位首个分歧点或验证修复，除非用户明确重新提高优先级。
  • 独立性能报告生产：不启动以全面跑分、跨项目排名或报告交付为目的的新任务。相关社区报告的解读是机制/优化分析中的必要证据章节，不是独立报告任务；报告观察与本地源码事实必须分开，且不自动视为当前基线的验证结果。

选择下一项研究时，应先明确它归属哪条主线、要回答的机制或优化问题、所需源码/实验依据，以及最小完成条件。样本工作仅在补齐上述问题的证据缺口时开展，可从 样本目录索引 按 template / seed / real / validated 筛选；偶然遇到暂缓领域线索时只记录关联，不据此重启任务。
